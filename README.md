# RPG Balatro Roguelite MVP (Unity, без внешних ассетов)

Проект переделан из караванного прототипа в компактный **RPG Balatro-like**: игрок проходит бесконечный забег по циклу
**бой → награда → магазин/улучшение → следующий бой → босс → новый акт → рост сложности → всё более безумный билд**.

Главная идея — не открытый мир, а плотная роглайт-петля, где каждый ход игрок собирает действие из карт-рун:

```text
Удар + Огонь + Крит = критический огненный удар
Щит + Лечение = регенерирующая защита
Молния + Повтор = цепная молния
Удар + Кровь = вампирский удар
```

## 1) Что уже есть в MVP

- один стартовый герой с HP, золотом, бронёй и моралью;
- стартовая колода воина из атак, щитов, лечения и элементальных рун;
- рука из 5 карт, выбор до 4 карт за ход (некоторые боссы ограничивают до 3);
- `ComboResolver`, который считает итоговое действие по тегам карт;
- враги и боссы с процедурными свойствами: броня, регенерация, сопротивление огню/критам, наказание за лечение;
- бесконечный рост сложности через этажи и акты;
- награда после боя: карта, золото, лечение, улучшение или артефакт за босса;
- магазин: купить карту, удалить слабую карту, улучшить карту, вылечиться;
- артефакты, которые усиливают теги и создают основу для сломанных билдов;
- старый стратегический экран оставлен как отдельный режим через HUD, но основной цикл теперь карточно-RPG.

## 2) Структура

```text
Assets/
  Scripts/
    Cards/       # карты, теги, колода, ComboResolver
    RPG/         # модель героя
    Enemies/     # враги, свойства, генератор врагов
    Rewards/     # награды и артефакты
    Run/         # состояние забега и бесконечный scaling
    Gameplay/    # состояния боя, награды, магазина, путешествия и bootstrap
    Core/        # state machine
    Data/        # общие ресурсы игрока
    Generation/  # генерация маршрута между боями/магазинами/боссами
    Events/      # старые события каравана
    Map/         # визуализация карты
    Strategy/    # отдельный стратегический режим
    UI/          # HUD, окна выбора, фабрика UI
  Tests/
    EditMode/    # unit-тесты стратегии, combo-системы, колоды и scaling
```

## 3) Быстрый запуск

1. Установите Unity **2022.3 LTS**.
2. Откройте папку проекта в Unity Hub.
3. Создайте сцену `Assets/Scenes/Main.unity`.
4. Создайте пустой объект `GameRoot`.
5. Добавьте на него компонент `GameBootstrap` (`Assets/Scripts/Gameplay/GameBootstrap.cs`).
6. Добавьте сцену в Build Settings как Scene 0.
7. Нажмите Play.

Камера, Canvas, HUD и фон создаются автоматически, поэтому сцена может быть пустой кроме `GameRoot`.

## 4) Основной игровой цикл

### Бой

В бою генерируется враг с учётом текущего этажа и акта. Игрок получает 5 карт и выбирает связку тегов. После нажатия **«Сыграть выбранное комбо»**:

1. выбранные карты уходят в сброс;
2. `ComboResolver` определяет название и базовые эффекты;
3. артефакты добавляют бонусы за теги;
4. свойства врага режут часть урона или меняют правила;
5. враг делает ответный ход;
6. игрок тянет новую руку.

### Награда

После победы игрок выбирает одну из трёх наград. Важный принцип: не всегда выгодно брать новую карту — иногда лучше лечиться или улучшать текущую колоду.

### Магазин

Магазин особенно ценен из-за удаления слабых карт. Чем тоньше колода, тем чаще собираются нужные синергии.

### Босс и акты

Босс может появиться на босс-узле маршрута или на босс-этаже. После победы над боссом:

```text
Акт увеличивается → враги получают больше HP/урона/брони → создаётся новый маршрут → забег продолжается
```

## 5) Как расширять игру

Самые полезные следующие шаги:

1. Перевести `CardDefinition`, `ArtifactDefinition`, `EnemyDefinition` и boss-правила в `ScriptableObject` assets.
2. Добавить экран выбора класса: воин, маг, разбойник, некромант.
3. Добавить 15–20 артефактов с более безумными правилами, а не только плоским бонусом к тегу.
4. Сделать отдельные UI-карты вместо кнопок в `ChoicePanel`.
5. Добавить таблицу рекордов по этажу/акту/собранному билду.

## 6) Тесты

EditMode-тесты проверяют:

- старый стратегический режим;
- сигнатурное комбо `Attack + Fire + Crit`;
- удаление слабых карт и минимальный размер колоды;
- рост HP, урона и брони врагов в бесконечном scaling.
